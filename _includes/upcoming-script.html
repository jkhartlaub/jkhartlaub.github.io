{%- comment -%} The site is only rebuilt on push, so "upcoming" is recomputed in the browser against today's date. Lists with data-upcoming-list: rows with data-date get .is-upcoming (date today or later). With data-reorder: upcoming rows first (soonest on top), then past rows (newest on top); data-max-past limits the past rows shown (0 = none, attribute missing = all). data-heading names the id of a heading whose text switches between data-text-upcoming and data-text-past. data-hide-if-none names the id of an element that is hidden when no row is upcoming. Without JavaScript the build-time state stays. {%- endcomment -%}
